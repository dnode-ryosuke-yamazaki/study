# ノートの削除API タスク

> TDDで進める。各タスクは 🔴 Red(失敗するテストを書く) → 🟢 Green(最小実装) → 🔵 Refactor の順で進める。

- [ ] 1. `DELETE /notes/{noteId}` のルーティングと `delete_note.py` のハンドラ骨格を作る(ノート削除API-1)
- [ ] 2. 認可済みトークンから利用者IDを取り出し、取れない場合は401を返す
- [ ] 3. 所有者一致を条件にした条件付き削除を実装し、成功時に204を返す(ノート削除API-2、削除できる対象-1)
- [ ] 4. 条件不一致(存在しない・他人のノート)で404を返す(削除できる対象-2、削除できる対象-3)
- [ ] 5. 削除後の取得が404になることを結合テストで確認する(削除できる対象-4)
- [ ] 6. 開始・404・500のログ出力を実装する
